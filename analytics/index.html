이벤트 읽는 법

Events에서 이벤트를 선택하고 Properties를 열면 논문·링크·깊이별로 비교할 수 있습니다.

이벤트의미비교 기준
cv-open공개 CV 링크 클릭방문자 수 대비 클릭 수
paper-link논문 자료 링크 클릭paper, resource
contact-clickEmail·Scholar·GitHub·LinkedInlabel
paper-view논문 항목이 1초 이상 화면에 노출paper
section-view섹션이 1초 이상 화면에 노출section
figure-open논문 그림 크게 보기 클릭paper
section-jump본문 내 바로가기 클릭destination
external-link기타 외부 링크 클릭label, target
scroll-depth문서의 25·50·75·90·100% 도달percent
visible-time15·30·60·120·300초 화면 유지seconds
visit-summary탭을 숨기거나 떠날 때 방문 요약visible_seconds, max_scroll
site-error사이트 코드·이미지 로드 오류type, source

클릭은 열람 완료를 뜻하지 않으며, 화면 노출 시간은 실제 읽은 시간과 다릅니다. 히트맵·세션 재생은 현재 무료 Cloud 범위에 포함되지 않습니다.
